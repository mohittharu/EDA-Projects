
📊 EDA-Projects

This repository contains a collection of Exploratory Data Analysis (EDA) projects focused on extracting insights, visualizing patterns, and understanding real-world datasets using Python.



## 📁 Projects Overview

| Day | Project Title | Description | Dataset Source |
|----|---------------|-------------|----------------|
| 1 | Project 01: FIFA Player Rating Analysis | Analyzing FIFA player data to understand ratings, performance, and player similarity | FIFA Player Dataset (Kaggle) |
| 2 | Project 02: Titanic Survival Analysis | Analyzing passenger data to identify survival patterns and influencing factors | Titanic Dataset (Kaggle) |
| 3 | Project 03: Movie Recommendation System | Building a movie recommendation system using EDA and similarity techniques to suggest movies | Movie Dataset (Kaggle / TMDB) |



📂 Folder Structure

The repository is structured as follows:

Project XX - ProjectName/
Each project folder contains:

data/: Raw and cleaned datasets used in the project

images/: Plots and visualizations generated during the analysis

Notebooks: A Jupyter Notebook (.ipynb) with complete data analysis

README.md: A detailed explanation of the project, including methodology and results

🚀 How to Use
Clone the Repository
git clone https://github.com/mohittharu/EDA-Projects.git

Navigate to the Repository
cd EDA-Projects

Open a Project

Navigate to any project folder and open the notebook using Jupyter Notebook or Jupyter Lab.
